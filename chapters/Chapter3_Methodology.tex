\subsection{Судалгааны төрөл}

Энэхүү дипломын ажил нь хавсарга судалгаа (Applied Research) төрөлд хамаарна. Өөрөөр хэлбэл, онолын ойлголт, өмнөх судалгааны үр дүнг боловсролын орчны бодит асуудлыг шийдэх програм хангамжийн шийдэл болгон хэрэгжүүлэхэд чиглэсэн. 

\subsection{Хөгжүүлэлтийн загвар}

Системийн хөгжүүлэлтэд Итератив (Iterative SDLC) загварыг сонгосон. Энэ загвар нь шаардлага эхний шатанд бүрэн тогтоогдоогүй үед нарийн давтамжтай сайжруулалт хийх, хэрэглэгчийн санал хүсэлтийг богино мөчлөг бүрт тусгаж, хөгжүүлэлтэнд гарах эрсдэлийг үе шаттай бууруулах зорилготой. Уламжлалт Waterfall загварт үе шатуудын хоорондын уялдаа шугаман шинжтэй, эргэх холбоо сул байдаг нь хэрэглэгчийн шинэ шаардлагыг хожуу тусгах, улмаар төслийн төгсгөлд таарамжгүй бүтэц үүсэх эрсдэлийг дагуулдаг бол итератив загвар нь хувилбар бүр дээр баталгаажуулалт хийж, алдааг эрт илрүүлэх боломжийг олгодог. Ялангуяа OCR (Текст таних), SRS (Давталтын алгоритм), болон Ranking (Үнэлгээний систем) зэрэг нарийн төвөгтэй логик модулиуд нь бодит туршилтын үр дүнгээс хамаарч дахин тохируулагдах шаардлагатай байдаг тул тэдгээрийг салангад бүтцээр хөгжүүлж, итераци бүрт чанарыг нь ахиулах замаар системийн тогтвортой байдлыг хангасан.

\subsection{Судалгааны объект, субъект}

\begin{itemize}
    \item \textbf{Судалгааны объект:} сургуулийн орчинд дижитал суралцах үйл явцыг дэмжих нэгдсэн платформын зохиомж
    \item \textbf{Судалгааны субъект:} оюутан, багш, админ гэсэн хэрэглэгчийн үндсэн бүлгүүд
    \item \textbf{Судалгааны хүрээ:} веб клиент, мобайл клиент, REST API, Supabase/PostgreSQL өгөгдлийн орчин
\end{itemize}

\subsection{Алгоритмын шийдлүүд}

\subsubsection{SRS алгоритм (SM-2)}

Флашкарт давталтыг SM-2 алгоритмаар хэрэгжүүлсэн. Гол параметрүүд нь \texttt{EF}, \texttt{interval}, \texttt{repetitions}, \texttt{next\_review} бөгөөд хэрэглэгчийн гүйцэтгэлийн үнэлгээнээс хамааран давталтын интервал динамикаар шинэчлэгддэг.

\[
I_1 = 1, \quad I_2 = 6, \quad I_n = I_{n-1} \times EF \; (n \ge 3)
\]

\subsubsection{Ranking систем}

Contribution оноог жинлэсэн нийлбэрийн ерөнхий загвараар тооцно:

\[
\mathrm{Score} = \sum_{i=1}^{n} w_i \cdot x_i
\]

энд $x_i$ нь $i$-р модуль дахь хэрэглэгчийн гүйцэтгэлийн үзүүлэлт, $w_i$ нь тухайн модулийн жин болно. Жишээлбэл, флашкарт, толь бичиг, нийтлэл, Q\&A, төслийн оролцоог тус бүр өөр жинтэйгээр нэгтгэнэ.

\subsubsection{Search логик}

Supabase/PostgreSQL-ийн full-text search механизмыг ашиглан нэр томьёо болон нийтлэлийн хайлтыг хэрэгжүүлсэн. Хайлтын чанарыг сайжруулахын тулд индексжүүлэлт, tag-т суурилсан шүүлт, эрэмбэлэх логикийг хавсаргасан.

\subsection{UI/UX дизайн}

\begin{itemize}
    \item Screen Flow: хэрэглэгчийн үүрэг бүрийн үндсэн урсгалын зураглал
    \item Wireframe: гол дэлгэцүүдийн бүтцийн загвар
    \item Дизайн систем: өнгө, typography, компонентын дахин ашиглалт
    \item Компонентын тогтвортой байдал: веб ба мобайл дээр ижил үйлдлийн логик, нэршил

\subsection{Хөгжүүлэлтийн явц}

Итераци төлөвлөгөөг дараах дарааллаар хэрэгжүүлсэн.

\begin{enumerate}[leftmargin=2em]
    \item Суурь бүтэц: authentication, navigation, layout
    \item Core модуль: flashcard, dictionary, Q\&A, article
    \item Extended модуль: contest, analytics, project log
    \item Нэгтгэл: ranking, profile, cross-module data flow
    \item Мобайл уялдаа: вебтэй ижил бизнес логикийг мобайлд нутагшуулах
\end{enumerate}

Git workflow-ийн хувьд feature branch стратеги баримталж, кодын хяналт, нэгтгэлийг pull request процессоор удирдсан.

\subsection{Туршилтын төлөвлөгөө}

\begin{itemize}
    \item Unit test: тусдаа функц, алгоритмын зөв ажиллагааг шалгах
    \item Integration test: модуль хоорондын API болон өгөгдлийн урсгал
    \item UAT (User Acceptance Testing): хэрэглэгчийн бодит сценари дээр баталгаажуулах
\end{itemize}

\subsection{Үнэлгээний шалгуур}

\begin{itemize}[leftmargin=2em]
    \item Системийн найдвартай ажиллагаа (алдаагүй үндсэн урсгал)
    \item OCR-ийн нарийвчлал (танилтын зөв хувь)
    \item Ранкинг логикийн зөв байдал (үйлдэл-онооны уялдаа)
    \item SRS давталтын үнэн зөв шинэчлэлт
    \item API хариуны тогтвортой гүйцэтгэл
\end{itemize}
