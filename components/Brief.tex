\noindent\textbf{1. Удиртгал}

Компьютерын ухааны тэнхимийн оюутнууд мэргэжлийн нэр томьёогоо ойлгох, бүтээлээ баримтжуулан хадгалах, мэдээллээ бусдадаа хуваалцахад үүсдэг хүндрэлүүд нь суралцахад тулгардаг урт хугацааны асуудал юм. Одоогоор эдгээр хэрэгцээг хангах орчин байхгүй тул оюутнууд олон тусдаа платформ дунд цагаа үрж, нөсөр эх сурвалжид төөрөх хандлагатай байдаг.

\noindent\textbf{1. Introduction}

Computer science students face ongoing challenges in understanding technical terminology, documenting their work, and sharing information with peers. Currently, there is a lack of a unified environment to fulfill these needs, causing students to waste time across multiple fragmented platforms and get lost in dense resources.

\noindent\textbf{1.1 Objective}

The objective of this thesis is to design a comprehensive web and mobile platform solution named \textbf{``FutureHub''} and develop its core prototype. The platform aims to support self-directed learning, enhance professional skills, and encourage knowledge and experience sharing among computer science students.

\noindent\textbf{1.2 Tasks}
\begin{itemize}[nosep]
    \item Identify user needs and define system requirements.
    \item Plan the system architecture and database design.
    \item Implement development and conduct testing.
    \item Evaluate the developed prototype results and outline future enhancements.
\end{itemize}

\noindent\textbf{2. Methodology}

The system features are classified into core and extended modules, designed for three user roles: student, instructor, and admin. In terms of the technology stack, the system comprises three main components: \textbf{Next.js} (web), \textbf{Flutter} (mobile), and \textbf{Supabase/PostgreSQL} (backend). \textbf{ML Kit} is utilized for OCR. Database search is optimized using GIN indexes and full-text search. Security is ensured through a three-tier protection layer consisting of \textbf{JWT + RBAC + RLS}, and version control is managed using Git/GitHub feature branch workflow.

\begin{center}
\includegraphics[width=0.95\linewidth]{pictures/futurehub-context.png}
\captionof{figure}{FutureHub system context diagram}
\label{fig:brief-context-diagram}
\end{center}
Development was executed in four primary phases: base infrastructure (authentication, navigation), core modules (dictionary, Q\&A, article), extended modules (contest, ranking, flashcard), and mobile conversion (Flutter). Testing was conducted at three levels—unit, integration, and UAT—verifying the SRS interval calculations, OCR workflow, RLS permission control, and cross-module data consistency.

\includegraphics[width=0.95\linewidth]{pictures/system-architecture.png}

\noindent\textbf{3. Results}

As a result of the research, the core prototype of the FutureHub system was successfully developed. The process flows and data relationships for both core modules (dictionary, Q\&A, article) and extended modules (contest, ranking, flashcard) were clearly defined. Additionally, role-based access control models were validated, establishing a flexible architectural foundation for future system scalability.

\noindent\textbf{4. Conclusion}

Although the system did not fully satisfy some secondary requirements from the initial plan, it successfully achieved its primary goals regarding core features and architectural solutions. The FutureHub platform integrates previously fragmented tools—such as SRS, OCR, dictionaries, Q\&A, and ranking systems—into a unified data core, creating a structured archive to document student knowledge. Testing demonstrated tangible outcomes, including optimization of student learning workflows, creation of a collaborative content ecosystem for knowledge sharing, and increased learning engagement driven by gamification (ranking) mechanisms. By refining the limitations of the current version, this solution can be readily adapted and deployed across other specialized academic disciplines in the future.
